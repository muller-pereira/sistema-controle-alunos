# Sistema de Controle de Alunos

## Objetivo

O Sistema de Controle de Alunos tem como objetivo auxiliar no gerenciamento
de informações acadêmicas dos estudantes, permitindo o registro e a consulta
de dados relacionados a alunos, notas e frequência.

## Principais funcionalidades

- Cadastro de alunos;
- Registro de notas;
- Consulta do desempenho dos alunos;
- Registro de frequência;
- Consulta da frequência;
- Geração de informações acadêmicas da turma.
